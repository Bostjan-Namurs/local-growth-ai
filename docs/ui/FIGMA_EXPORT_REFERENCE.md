# Figma Make Export Reference

The Figma Make generated code snapshot is located at:

`design/reference/figma-make-export/`

Use it only as a design/reference source.

Codex may inspect:
- screen layout
- navigation structure
- sample copy
- visual hierarchy
- component ideas
- spacing patterns
- status labels
- approval flows

Codex must not:
- replace `apps/web` with the Figma export
- copy generated code blindly
- modify the reference export
- introduce unrelated dependencies from the export
- change backend code while implementing UI screens

The production Admin UI must be implemented in:

`apps/web`
